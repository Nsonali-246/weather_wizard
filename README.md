#  Weather Wizard

An interactive computer vision project that uses hand gesture recognition to simulate weather effects in real-time.

##  Features

* ✋ Hand tracking using MediaPipe
* ☔ Rain simulation (1 finger)
* ❄️ Snow simulation (2 fingers)
* ⚡ Lightning effect (3 fingers)
* 🌤️ Clear sky mode

##  Tech Stack

* Python
* OpenCV
* MediaPipe
* NumPy

##  How to Run

```bash
pip install -r requirements.txt
python weather_wizard.py
```
